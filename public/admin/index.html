Import câu hỏi

Hỗ trợ file .json và .xlsx

Kéo thả file vào đây hoặc nhấn để chọn

.json (mảng câu hỏi)  ·  .xlsx (mỗi dòng một câu hỏi)

Xem hướng dẫn định dạng file ▾

JSON: Mảng các object với các trường: title, description, question_type (single/multiple/matching/ordering), choices (mảng chuỗi), correct_index (số, cho single), correct_answer (mảng, cho multiple/matching), explanation, tags, difficulty (0-5).

XLSX: Hàng đầu tiên là tiêu đề cột với đúng tên trường trên. Cột choices và correct_answer là chuỗi JSON (ví dụ: ["A","B","C"]). Cột tags có thể là chuỗi phân cách bằng dấu phẩy.

⬇ Tải file JSON mẫu  ·  ⬇ Tải file XLSX mẫu (15 câu hỏi AI trong BA)
